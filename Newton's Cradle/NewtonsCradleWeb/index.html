Newton's Cradle

The desk toy: steel spheres that pass the impulse end to end. Lift two or three together and the same number swings out the other side. Nothing to win: it is there to be watched.
Desktop
  • Drag a sphere aside and release it to set the others going.
  • Add a ball / Remove a ball change how many hang.
  • Ghost mode makes them pass through each other instead of colliding.
  • Freeze pauses gravity and leaves them where they are.
  • Restart hangs them back at rest.
Mobile
  • Drag a sphere and release it; the bar buttons behave the same as on desktop.
The room runs a day-night cycle of about a minute. It does nothing: it is there so you can tell time is passing.
