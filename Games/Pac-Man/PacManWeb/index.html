Pac-Man

Eat every pellet without being caught. You start with three lives and earn one more at 10,000 points. The power pellets in the corners turn the ghosts blue for a few seconds and you can eat them, and each one in a row is worth more than the last (200, 400, 800, 1600). Clearing the maze moves you to the next one.
Desktop
  • Arrow keys or WASD set the direction. Pac-Man keeps going until the next turn.
  • Back to the menu in the bar, where the mode and the skin are chosen: Classic, Hard, Marathon (it starts at level 6, already with the fast ghosts) and Daily, which is the same run for everyone that day.
Mobile
  • Swipe in the direction you want to go, anywhere on the screen.
The background siren rises in pitch as the maze empties.
